Engineering Workflow

Mac 本地开发 - 服务器测试 - GitHub 协作

本地 Mac 是开发工作台，GitHub 是代码事实源，服务器或 HPC 是实验与验证环境。

核心原则

AI coding agent 适合在本地参与阅读、重构、测试生成和提交；服务器适合承担 GPU 训练、大规模测试、benchmark 与复现实验；GitHub 负责版本、协作、PR 和审查。

推荐闭环

本地开发 → 本地测试 → push 到个人分支
→ 服务器拉取测试 → 回传日志 → 修复 → PR 到团队 dev

角色边界

  • 本地负责轻量开发和 AI agent 辅助编码。
  • GitHub 负责版本事实源、分支管理与 Pull Request。
  • 服务器负责资源密集型测试、训练和评估。

实践意义

这套工作流的目标是减少“代码只在某台机器上存在”的风险，让实验、日志、修复和审查形成可复盘的工程链路。
